## How i want my language to look like
### The `main()` function

The `main()` function basically tells the computer and the underlying systems where to start the program, it is usually called by a `_start()` function already provided by the compiler

```c
#include <stdio.h>
int main(void) {
    printf("Hello World\n");
    return 0; 
}
```

Which results in `Hello World` and a new command prompt, while this syntax may be familliar to everyone, i find it a little "outdated" and blocky (especially the preprocessor directive)

Let's take a look at C# and Rust for the same purpose

```csharp
using System; // considering you don't have a global using

class Program {
    static void Main(string[] args) {
        Console.WriteLine("Hello World !!");
    }
}
```

```rust
fn main() {
    println!("Hello World !");
}
```

My ideas are the following :

### 1 : Main Function
```
func main() : void {
    // Some freestanding code
}
```

### 2 : A custom entrypoint
```
entrypoint () : void {
    // Some freestanding code
}
```
The second option would make an anonymous entrypoint for the code to start <br>
To be easily executable, the default name of an anonymous entrypoint is `_start()`

If you do this :

```
entrypoint e1() : i8 {
    // Some code
    return 0;
}

entrypoint e2() : i8 {
    // Some code
    return 0;
}
```

Multiple entrypoints are defined, you can, using this (since this language compiles to LLVM), give multiple entry points an assembly code, and select which one to trigger, example with the following bootloader

```x86asm
[bits 16]
[org 0x7c00]

; Extern symbols
extern e1 ; entrypoint e1()
extern e2 ; entrypoint e2()

start:
    mov al, 1 ; we want to trigger e2

    ; comparison with a JUMP EQUAL flag condition
    cmp al, 0
    je trig_e1

    cmp al, 1
    je trig_e2

    ; if none, stops locks the cpu
    jmp halt

trig_e1:
    call e1
    jmp halt

trig_e2:
    call e2
    jmp halt

halt:
    cli ; disables interruptions
    hlt ; locks the CPU
    jmp halt ; infinite loop (while (true))

; Bootloader signature
times 510-($-$$) db 0
dw 0xaa55
```

## Defining what's an identifier and a keyword
Both entries are in fact, words, in every language, they follow the regex expression defined as `[_a-zA-Z]+` <br>
The regex expression captures one ore more of underscore and letters at any position

## Designing the word parsing algorithm
I can start looking for those entries in my lexer and ignore the rest in my lexing algorithm <br>

I then thought of how is it going to work, let's look at our regex expression
```cpp
/*
Let the following regex expression : [_a-zA-Z]+
This expression checks for AT LEAST ONE of those characters in any sequence :
=> UNDERSCORES        (0x5F)
=> LOWER CASE LETTERS (0x61 -> 0x7A)
=> UPPER CASE LETTERS (0x41 -> 0x5A)

The sequence breaks if a symbol or a whitespace is detected
Each character will be parsed until the mentionned above condition reports true 
Every parsed character will be placed inside a string
*/
```

1. A character to parse
2. A string to store every character parsed forming a word
3. A way of checking if the current character is a whitespace or a symbol to stop parsing

The character is provided by a specific member of the lexer (more details in) `documentation/modules/Module2_Lexer.md`
```cpp

``` 

Where `iteratableBuffer<T>` is a custom made type exposing those functions that i will use :
```cpp
/**
 * Returns the current element without advancing the index cursor
*/
[[nodiscard]] const T& currentElement() const {
    if (isAtEnd()) {
        static const T default_value{};
        return default_value;
    }
    return _data[_idx];
}

/**
 * Returns the current element and advances the index cursor
*/
[[nodiscard]] T advance() {
    if (isAtEnd()) return T{};
    T element = _data[_idx]; 
    _idx++;
    return element;
}
```

What do i put in the execution condition of the while loop ? Remember : <br>
```cpp
/*
The sequence breaks if a symbol or a whitespace is detected
Each character will be parsed until the mentionned above condition reports true 
*/
```
I then need a way to check if the current character reports as a valid whitespace char, which are those : <br>
`WS`, `\n`, `\f`, `\r`, `\t` and `\v`

The `std` namespace has a function to assert if the given character is a space character
```cpp
// cppreference.com
// defined in <cctype>
int isspace( int ch );
```

I can use that to check if my current character is a whitespace before being parsed, however <br>
The https://en.cppreference.com/cpp/string/byte/isspace page states that
> Like all other functions from `<cctype>`, the behavior of `std::isspace` is undefined if the argument's value is neither representable as `unsigned char` nor equal to `EOF`. <br>
> To use these functions safely with plain `chars` (or `signed chars`), the argument should first be converted to `unsigned char`

To convert something in C++, the safest way to do is :
```cpp
static_cast<type>(entry)
```

The condition, using the lexer's buffer would then be :
```cpp
while (!std::isspace(static_cast<unsigned char>(charBuffer.currentElement()))) {}
```
This basically tells me **loop until the current element of the character buffer is a whitespace**

The reading algorithm is now pretty simple :
1. Read the next character in stream
2. Append it in the string

```cpp
while (!std::isspace(static_cast<unsigned char>(charBuffer.currentElement()))) {
    lexeme += charBuffer.advance();
}
```

Now you might ask yourself, what the hell is difference between this and 
```cpp
while (!std::isspace(static_cast<unsigned char>(charBuffer.advance();))) {
    lexeme += charBuffer.currentElement()
}
```

This version checks, by reading
1. If the next character is a whitespace
2. Then appends the current one to the string

It is technically working, but remember the definition of the `advance()` function

```cpp
[[nodiscard]] T advance() {
    if (isAtEnd()) return T{};
    T element = _data[_idx]; 
    _idx++;
    return element;
}
```

This version is, return wise, **the exact same** as the `currentElement()` function, in fact, i can simply it
```cpp
[[nodiscard]] T advance() {
    if (isAtEnd()) return T{}; // Returns a default element if out of bounds
    
    T element = currentElement();
    _idx++;
    return element;
}

// Even more compact
[[nodiscard]] T advance() {
    if (isAtEnd()) return T{};
    return _data[_idx++]; // Uses postfix incrementation
}
```

This would simply return the current element, and advance the cursor, the space would then be parsed as well ! <br>
This is why we check first if the current element isn't a whitespace, then we can append that element to the container before proceeding to the next element <br>

I'll also make generic functions to see if an item belongs to a vector
```cpp
#ifndef VEC_UTILS_HPP
#   define VEC_UTILS_HPP

#include <vector>
#include <algorithm>

namespace photon {
    /** 
     * Asserts that an element is present in a vector (pass by reference)
     * @param item The item to look for
     * @param vec The vector to check into
    */
    template<typename T>
    bool isItemRefPresentIn(T& item, const std::vector<T>& vec) {
        return (std::find(vec.begin(), vec.end(), item) != vec.end());
    }

    /** 
     * Asserts that an element is present in a vector
     * @param item The item to look for
     * @param vec The vector to check into
    */
    template<typename T>
    bool isItemPresentIn(T item, const std::vector<T>& vec) {
        return (std::find(vec.begin(), vec.end(), item) != vec.end());
    }
}

#endif
```

I will use the `isItemRefPresentIn()` function to avoid copies of the lexeme <br>
I will pass this function to an `if` statement and two arguments to the function <br>

1. The lexeme itself
2. The keyword list to see if one of its entries match against the lexeme 

After that, we can return a `Token` struct

```cpp
Token readWord(char& begin) {
    /* reading algorithm */

    // Checks if the lexeme refers to a known keyword
    if (isItemRefPresentIn(lexeme, reservedKeywords)) {
        return {TokenType::KEYWORD, lexeme};
    }

    return {TokenType::IDENTIFIER, lexeme};
}
```

### *Plugging inside the lexing algorithm*
Now to use this with my lexer, i have to first make the function stub

```cpp
/** Transforms the cleaned source file into a stream of tokens 
 * Note : The token stream will ALWAYS contain the following token :
 * - END_OF_FILE token
 * 
 * If anything goes wrong during the lexing pass, this token only will remain inside the token stream
 * To get the processed stream, use the provided getTokens() function
 */
void applyLexerPass(void);
```

The implementation begins with the following

```cpp
#include "translation/pLexer.hpp"


namespace photon {
    void pLexer::applyLexerPass() {
        if (charBuffer.isEmpty()) {
            auto logFrame = pLogger::buildFrame
            (
                IdPrefix::LEXER_LOG, SeverityPrefix::ERR, 0x02, 
                {"Empty char buffer, will not resume lexing process" }
            );

            pLogger::lprint(logFrame);
            tokenBuffer.addElement({TokenType::END_FILE, "EOF"}); 

            return;
        } 
            
        // Main lexing loop
        while (!charBuffer.isAtEnd()) {
            char c = charBuffer.advance();

            // Check for whitespaces to ignore
            if (isWhitespace(c)) { continue; }
        }

        tokenBuffer.addElement({TokenType::END_FILE, "EOF"}); 
    }
} // namespace photon
```

To call the function, we first need to assert that the current char is a potential identifier or keyword starter using this function, or assert that the character is `_` <br>

```cpp
// pLexer.hpp
/**
 * Asserts that the given character is a letter
 * @param c The given character
*/
bool isLetter(const char& c) {
    return std::isalpha(c);
}

// pLexer.cpp
#include "translation/pLexer.hpp"


namespace photon {
    void pLexer::applyLexerPass() {
        /* safety checks */
            
        // Main lexing loop
        while (!charBuffer.isAtEnd()) {
            char c = charBuffer.advance();

            // Check for whitespaces to ignore
            if (isWhitespace(c)) { continue; }

            // [NEW] Check for identifiers and keywords
            if (isLetter(c) || c == '_') { tokenBuffer.addElement(readWord(c)); }
        }

        tokenBuffer.addElement({TokenType::END_FILE, "EOF"}); 
    }
} // namespace photon
```
