## 1 : Symbols
Symbols are characters that can compose :
1. Program Structure
2. Operators
3. Special Instructions

All the following characters can be used to make operators <br>
`+, -, /, *, %, =, <, >, &, !, ~, |, ?`

I should note that i will NOT hardcode operators into the compiler <br>
Instead, and this will allow for custom operators, they will have base declarations and definitions to be mapped to assembly functions in the core lib of the compiler <br>

All the following characters are reserved and thus cannot be used to make operators <br>
`',', ';', ':', @, #`

The symbols will be stored in this list

### *Detecting Symbols*

To detect symbols, we will simply reuse our function
```cpp
/** 
 * Asserts that an element is present in a vector
 * @param item The item to look for
 * @param vec The vector to check into
*/
template<typename T>
bool isItemPresentIn(T item, const std::vector<T>& vec) {
    return (std::find(vec.begin(), vec.end(), item) != vec.end());
}
```

Then wrap it inside an another function that returns a boolean value
```cpp
/**
 * Asserts that the given character is a symbol
*/
bool isSymbol(const char& c) {
    return (isItemPresentIn(c, symbols));
}
```

The first thing i'll use this function for, is my word parsing algorithm, which includes symbols in the lexeme, to now filter those symbols <br>

### *Extracting symbols from a stream*

I can make a function that behaves similarly to the `readWord()` function, but with a much simpler condition

First, here is the signature of the function
```cpp
/**
 * Reads a symbol from the first character until the next non symbol character and returns a token
 * @param begin The first character to begin from
*/
Token readSymbol(char& begin) {

}
```

The skeleton is going to be the same
```cpp
Token readSymbol(char& begin) {
    std::string lexeme;
    char c = begin;
    lexeme += c;
    
    while () {
        lexeme += charBuffer.advance();
    }

    return {TokenType::SYMBOL, lexeme};
}
```
The condition is simply going to be **loop until the next character is a non symbol value only if the symbols can be combined** <br>
To do this, we'll use the `isSymbol(charBuffer.currentElement())` condition
```cpp
Token readSymbol(char& begin) {
    std::string lexeme;
    char c = begin;
    lexeme += c;
    
    
    while (isSymbol(charBuffer.currentElement())) {
        if (isItemPresentIn(charBuffer.currentElement(), combinableSymbols)) {
            lexeme += charBuffer.advance();
        } else {
            break;
        }
    }

    return {TokenType::SYMBOL, lexeme};
}
```

### *Plugging inside the lexing algorithm*
I'll simply check if the first character is a known symbol and call the function from there

```cpp
void pLexer::applyLexerPass() {
    /* safety checks */

    // Main lexing loop
    while (!charBuffer.isAtEnd()) {
        char c = charBuffer.advance();

        // Check for whitespaces to ignore
        if (isWhitespace(c)) { continue; }

        // Check for identifiers and keywords
        if (isLetter(c) || c == '_') { tokenBuffer.addElement(readWord(c)); }

        // [NEW] Check for symbols
        if (isSymbol(c)) { tokenBuffer.addElement(readSymbol(c)); }
    }

    tokenBuffer.addElement({TokenType::END_FILE, "EOF"}); 
}
```

## 2 : Numbers
Numbers can be written in those formats
```cpp
0123456789    // Integers
01.23456789   // Floats

// Special Formating
0b // Binary
0o // Octal
0x // Hexadecimal

// Scientific Notation
1(eE)(+-)23456789 // 1 * (10^x), is considered a float
```

Negative numbers are to be processed by the parsing unit

### Defining the rules to parse numbers
Numbers are parsed according to those regex expressions <br>
*(Made in https://regex101.com/, test regex expressions here !)*
```cpp
0123456789  // => Integers           : [0-9]+
0.123456789 // => Floats             : (?:[0-9]+\.?[0-9]*|\.[0-9]+)(?:[eE][+-]?[0-9]+)?

// Integers formatting
0b11        // => Binary Format      : 0[bB][0-1]+
0o77        // => Octal Format       : 0[oO][0-7]+
0xFF        // => Hexadecimal Format : 0[xX][0-9a-fA-F]+

// Floats formatting
0x1.5p3    // => Hexadecimal Format  : 0[xX](?:[0-9a-fA-F]+\.?[0-9a-fA-F]*|\.[0-9a-fA-F]+)[pP][+-]?[0-9]+
```

I will complete the `TokenType` enum to support every number type
```cpp
enum class TokenType {
    // Literals
    IDENTIFIER,         // A name in the code
    STRING,             // Text between "" markers
    CHAR,               // A character between '' markers
        
    // [NEW] Subcat : NUMBERS
    INT,                // Integer
    INT_BIN_FORMAT,     // 0b formated integers
    INT_OCT_FORMAT,     // 0o formated integers
    INT_HEX_FORMAT,     // 0x formated integers

    FLOAT,              // Floating point
    FLOAT_HEX_FORMAT,   // 0x formatted floats

    // Structural
    KEYWORD,            // A specific instruction
    SYMBOL,             // A symbol in the code

    // Delimitations
    END_FILE,           // EOF

    // [NEW] Misc
    INVALID             // An invalid token
};
```

### Defining the algorithm
Using the `<regex>` library, i will create a new file where i will place regex rules to match

```cpp
#ifndef PHOTON_REGEX_RULES_HPP
#   define PHOTON_REGEX_RULES_HPP

#include <string>
#include <regex>
#include <vector>
#include "pToken.hpp"

namespace photon {
    const std::vector<std::pair<TokenType, std::regex>> NUMBER_RULES = {

        // Hexadecimal Float (Matches 0x1.5p3, -0x.Ap-2)
        {TokenType::FLOAT_HEX_FORMAT, std::regex("^0[xX](?:[0-9a-fA-F]+\\.?[0-9a-fA-F]*|\\.[0-9a-fA-F]+)[pP][+-]?[0-9]+")},

        // Hexadecimal Integer (Matches 0xFF, 0X1A)
        {TokenType::INT_HEX_FORMAT,   std::regex("^0[xX][0-9a-fA-F]+")},
        
        // Binary Integer (Matches 0b1101)
        {TokenType::INT_BIN_FORMAT,   std::regex("^0[bB][0-1]+")},
        
        // Octal Integer (Matches 0o77)
        {TokenType::INT_OCT_FORMAT,   std::regex("^0[oO][0-7]+")},
        
        // Decimal Float (Matches 0.123, .45, 1e5)
        {TokenType::FLOAT,            std::regex("^(?:[0-9]+\\.[0-9]*|\\.[0-9]+)(?:[eE][+-]?[0-9]+)?|^[0-9]+[eE][+-]?[0-9]+")},

        
        // Decimal Integer (Matches 12345)
        {TokenType::INT,              std::regex("^[0-9]+")}

    };
}


#endif
```

We will need multiple informations

```cpp
Token readNumber() {
    size_t startPos = charBuffer.position() - 1; // because we did "advance()" before

    auto current_it = charBuffer.begin() + startPos;
    auto end_it = charBuffer.end();

    std::match_results<decltype(current_it)> match;
}
```

Then, we need to iterate over the number matches list

```cpp
Token readNumber() {
    /* declarations */

    for (const auto& rule : NUMBER_RULES) {}
}
```

The algorithm itself is going to be the following
1. If a match occurs, we retrieve the lexeme
2. Then, we consume the entire number using `match.length() - 1;`
3. We return the token

I will also use `std::regex_constants::match_continuous` to not overload the regex parser

```cpp
Token readNumber() {
    /* declarations */

    for (const auto& rule : NUMBER_RULES) {
        if (std::regex_search(current_it, end_it, match, rule.second, std::regex_constants::match_continuous)) {
            std::string lexeme = match.str();

            size_t charsLeft = match.length() - 1;
            for (size_t i = 0; i < charsLeft; ++i) {
                charBuffer.advance();
            }

            return { rule.first, lexeme };
        }
    }
}
```

### *Plugging inside the lexing algorithm*
I'll simply check if the first character is a number or a dot

```cpp
while (!charBuffer.isAtEnd()) {
    char c = charBuffer.advance();

    // Check for whitespaces to ignore
    if (isWhitespace(c)) { continue; }

    // Check for identifiers and keywords
    if (isLetter(c) || c == '_') { 
        tokenBuffer.addElement(readWord(c)); 
        continue;
    }

    // [NEW] Check for numbers
    if (std::isdigit(c) || (c == '.' && std::isdigit(charBuffer.currentElement()))) {
        tokenBuffer.addElement(readNumber());
        continue;
    }

    // Check for symbols
    if (isSymbol(c)) { 
        tokenBuffer.addElement(readSymbol(c)); 
        continue;
    }

    // [NEW] Fallback
    else {
        tokenBuffer.addElement({ TokenType::INVALID, "invalid" });
    }
}
```

## 3 : Strings and Chars

Strings and chars are parsed the same way by the lexer, it's the parser's job to truncate excess characters inside a char value <br>

### Defining the rules to parse strings and chars

Two delimiters define strings and chars and the text wrapped inside are the values :
1. `"` delimits strings
2. `'` delimits chars

### Creating the algorithm

The algorithm
1. Gets the delimiter
2. Parses the lexeme until the next delimiter (it must be the same delimiter)
3. Creates a new token

Let's define the following function
```cpp
/**
 * Reads a string value or char value between two matching delimiters
 * @param delimiter The symbol that delimits the value
*/
Token readStringOrChar(char delimiter) {}
```

The parsing condition is to loop until one of the two delimiters is reached to stop execution <br>
The token is invalid if :
1. The end of stream is reached without finding the next delimiter
2. The delimiters do not match

Implementing this is easy
```cpp
Token readStringOrChar(char delimiter) {
    std::string lexeme = "";
            
    while (charBuffer.currentElement() != delimiter) {
        if (charBuffer.isAtEnd()) {
            return { TokenType::INVALID, "invalid" };
        }

        if (charBuffer.currentElement() == '\\') {
            charBuffer.advance();
                    
            if (charBuffer.isAtEnd()) {
                return { TokenType::INVALID, "invalid" };
            }
                        
            char escaped = charBuffer.advance();

            switch (escaped) {
                case 'n':  lexeme += '\n'; break; 
                case 't':  lexeme += '\t'; break; 
                case 'r':  lexeme += '\r'; break; 
                case '"':  lexeme += '"';  break; 
                case '\'': lexeme += '\''; break; 
                case '\\': lexeme += '\\'; break; 
                default: 
                        lexeme += '\\';
                        lexeme += escaped;
                        break;
            }
            continue;
        }

        lexeme += charBuffer.advance();
    }

    charBuffer.advance(); 

    if (delimiter == '\'') {
        return { TokenType::CHAR, lexeme };
    } else {
        return { TokenType::STRING, lexeme };
    }
}
```
